Iris Data Cleaning and Visualization

 Project Overview

This project demonstrates a complete data cleaning, preprocessing, exploratory data analysis (EDA), and data visualization workflow using the Iris dataset.

The project was developed using Python and focuses on preparing the data, analyzing its main characteristics, and creating meaningful visualizations.

 Objectives

The main objectives of this project are to:

- Inspect the dataset structure and data types
- Identify and analyze missing values
- Detect and remove duplicate records
- Standardize categorical data
- Calculate descriptive statistics
- Analyze relationships between numerical variables
- Create different types of visualizations
- Export charts as PNG images

 Technologies and Libraries

- Python
- Pandas
- Matplotlib
- Seaborn
